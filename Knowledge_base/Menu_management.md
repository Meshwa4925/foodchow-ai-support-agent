# Menu Management

## Menu Not Updating

If menu changes are not reflected:

1. Check menu sync status.
2. Check the last update time.
3. Verify the outlet.
4. Retry synchronization.
5. Escalate if synchronization fails.

## Item Availability

If an item should be available:

1. Check the current item availability.
2. Verify the outlet menu.
3. Update availability only if authorized.
4. Confirm the change.
