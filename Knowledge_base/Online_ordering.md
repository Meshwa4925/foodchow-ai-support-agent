# Online Ordering Troubleshooting

## Cannot Place Online Order

If customers cannot place an online order:

1. Check whether the outlet is active.
2. Check menu availability.
3. Verify item availability.
4. Check whether the ordering service is working.
5. Escalate if the issue continues.

## Menu Changes Not Appearing Online

If menu changes are not visible online:

1. Check the menu sync status.
2. Verify the last menu update time.
3. Retry menu synchronization.
4. Check item availability.

If synchronization fails repeatedly, escalate to support.

## Sold Out Item

If an item is showing as sold out:

1. Check item availability in the menu.
2. Verify outlet menu configuration.
3. Update item availability if authorized.
4. Confirm that the item is visible correctly.
