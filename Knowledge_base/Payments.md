# Payment Troubleshooting

## Payment Deducted but Order is Pending

If payment was deducted but the order is still pending:

1. Get the order information.
2. Check the order status.
3. Check the payment status.
4. Compare order and payment states.
5. Explain the mismatch to the customer.
6. Do not issue a refund automatically.
7. Escalate if payment investigation or refund approval is required.

## Payment Successful but Order Failed

If payment is successful but the order failed:

1. Retrieve the order.
2. Retrieve payment information.
3. Compare order and payment status.
4. Do not perform a refund without authorization.
5. Create a support ticket if manual investigation is required.

## Refund

Refunds are controlled actions.

Before processing a refund:

1. Verify the order.
2. Verify payment.
3. Check refund eligibility.
4. Calculate the refund amount.
5. Obtain required approval.
6. Execute the refund only when authorized.
