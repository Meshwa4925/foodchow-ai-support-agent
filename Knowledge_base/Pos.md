# POS Troubleshooting

## POS Sync Issue

If the POS is not syncing with FoodChow:

1. Check the internet connection.
2. Verify that the POS application is running.
3. Restart the POS application.
4. Check whether the outlet is active.
5. Retry synchronization.

If the problem continues, collect outlet information and escalate to support.

## GST and Billing Issue

If GST or billing information looks incorrect:

1. Verify the restaurant and outlet configuration.
2. Check the applicable tax settings.
3. Verify the bill amount.
4. If the issue cannot be resolved, escalate to support.

## POS Offline Issue

If POS is offline:

1. Check internet connectivity.
2. Check whether the POS application is running.
3. Restart the application.
4. Check outlet status.
5. Escalate if the POS remains offline.

## Printer Issue from POS

If bills are not printing:

1. Check printer connection.
2. Check printer status.
3. Verify that the correct printer is configured.
4. Restart the printer.
5. Retry printing.
