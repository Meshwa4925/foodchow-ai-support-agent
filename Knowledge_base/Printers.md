# Printer Troubleshooting

## Printer Offline

If a printer is offline:

1. Check the printer power.
2. Check the network or USB connection.
3. Verify printer status.
4. Restart the printer.
5. Retry printing.

If the printer remains offline, create a support ticket.

## Printer Not Printing

If the printer is online but does not print:

1. Verify printer configuration.
2. Check the connection.
3. Check whether another print job is stuck.
4. Restart the printer.
5. Retry printing.

If printing still fails, escalate to support.
