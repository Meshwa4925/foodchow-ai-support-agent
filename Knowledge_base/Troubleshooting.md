# General Troubleshooting

## Diagnostic Process

When a customer reports an issue:

1. Understand and classify the issue.
2. Search the knowledge base.
3. Ask for missing information.
4. Call the relevant diagnostic tool.
5. Analyze the tool result.
6. Identify the likely root cause.
7. Explain the issue to the customer.
8. Provide troubleshooting steps.
9. Ask whether the issue is resolved.
10. Escalate if necessary.

## Tool Failure

If a diagnostic tool fails:

1. Do not invent a result.
2. Explain that the system could not retrieve the required information.
3. Retry when appropriate.
4. Escalate if the problem continues.

## Missing Information

If required information such as order ID or outlet ID is missing, ask the customer for it before performing the relevant investigation.

## Escalation

Escalate when:

- Confidence is low.
- There is a payment dispute.
- A refund requires approval.
- There is an account security issue.
- There is a critical POS outage.
- Troubleshooting has repeatedly failed.
- A backend/API failure prevents investigation.
